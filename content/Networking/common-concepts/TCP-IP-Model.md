# TCP/IP Model

The **TCP/IP model** is a concise networking model and a set of communications protocols used for the Internet and similar networks.

While the [[OSI Model]] has 7 layers, the TCP/IP model simplifies this into 4 layers:

## The 4 Layers

1. **Network Access Layer**: Corresponds to OSI Layers 1 and 2. Handles physical connections and MAC addressing.
2. **Internet Layer**: Corresponds to OSI Layer 3. Handles IP addressing and routing.
3. **Transport Layer**: Corresponds to OSI Layer 4. Handles host-to-host communication (TCP, UDP).
4. **Application Layer**: Corresponds to OSI Layers 5, 6, and 7. Handles high-level protocols like HTTP, DNS, and SSH.

This model is often seen as more practical for modern network architecture compared to the conceptual OSI model.
